# Jovanie Montajes — Portfolio

Responsive single-page portfolio (static HTML/CSS/JS, no build step).

## Run locally
Open `index.html` in a browser.

## Deploy (Vercel)
Import this folder as a project. No build command; output directory is the root.

## Things you can edit
- Email: `jovaniedionesmontajes@gmail.com` (search for it in `index.html` and `script.js`).
- Services (section `#services`): adjust or remove the cards to match what you really offer.
- Add GitHub/LinkedIn links near the footer or contact section if you want them.
- Contact form opens the visitor's email app (mailto). For in-page sending, connect a service like Formspree later.
