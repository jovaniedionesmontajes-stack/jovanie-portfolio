# Jovanie Montajes — Portfolio

A responsive, single-page Creative Developer portfolio.

## Run locally
Open `index.html` in a browser, or serve this folder with a local static server.

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html` with your professional email address.
2. Confirm that the profile photo in `assets/profile.png` is the image you want to publish.
3. Review the project description and role-based access description against the deployed application's actual behavior.
4. Add GitHub/LinkedIn links if you want them displayed.
5. Test the live site on mobile and desktop.

## Deploy
This is a static site and can be deployed to Vercel by importing the folder/repository. No build command is required; use the project root as the output directory.

## Accuracy note
The project page describes only the functionality supplied for this portfolio: daily EOD entries, branch variances, follow-up actions, Supabase, Vercel, and role-based login/access. It does not claim measured business results or client outcomes.
